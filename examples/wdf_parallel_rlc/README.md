# Parallel RLC resonator

A parallel RLC load driven through a source resistor. It exposes the resonant branch voltage and the complementary notch across the source resistor.

Entry point: parallel_rlc(x, frequency, q).

References: [parallel adaptor](https://www.dsprelated.com/freebooks/pasp/General_Parallel_Adaptor_Force.html), [wave digital elements](https://www.dsprelated.com/freebooks/pasp/Physical_Derivation_Wave_Digital.html).
