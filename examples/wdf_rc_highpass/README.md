# RC high-pass

First-order series RC WDF. The output is measured across the resistor; cutoff spans 0.001–0.25 of the sample rate.

Entry point: rc_highpass(x, cutoff).

References: [wave digital elements](https://www.dsprelated.com/freebooks/pasp/Physical_Derivation_Wave_Digital.html), [series adaptor](https://www.dsprelated.com/freebooks/pasp/General_Series_Adaptor_Force.html).
