# Pre-amp EQ

The four-capacitor linear EQ used in the `wdf_compiler` benchmarks. It is a series/parallel WDF tree and needs no R-type adaptor.

References: [paper, fig. 3](https://dafx26.mit.edu/assets/papers/DAFx26_paper_23.pdf), [`wdf_compiler` circuit](https://github.com/Chowdhury-DSP/wdf_compiler/blob/main/tests/preamp_eq/preamp_eq.wdf).
