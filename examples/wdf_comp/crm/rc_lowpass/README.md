# RC lowpass

The RC lowpass used in the `wdf_compiler` paper: 1 kΩ in series with 1 µF, output across the capacitor.

References: [paper, fig. 1](https://dafx26.mit.edu/assets/papers/DAFx26_paper_23.pdf), [`wdf_compiler` circuit](https://github.com/Chowdhury-DSP/wdf_compiler/blob/main/tests/rc_lowpass/rc_lowpass.wdf).
