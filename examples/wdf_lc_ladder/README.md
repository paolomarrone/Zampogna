# Third-order LC ladder

Matched L–C–L Butterworth ladder using normalized prototype values 1–2–1. It exercises nested series and parallel adaptors.

Entry point: lc_ladder(x, cutoff).

References: [wave digital elements](https://www.dsprelated.com/freebooks/pasp/Physical_Derivation_Wave_Digital.html), [series and parallel adaptors](https://www.dsprelated.com/freebooks/pasp/Adaptors_Wave_Digital_Elements.html).
