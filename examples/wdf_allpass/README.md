# First-order all-pass

Capacitor reflectance realized as a one-pole all-pass. Cutoff controls phase while magnitude remains unity.

Entry point: wdf_allpass(x, cutoff).

References: [element reflectances](https://www.dsprelated.com/freebooks/pasp/Physical_Derivation_Wave_Digital.html), [PyWDF passive all-pass example](https://www.dafx.de/paper-archive/2023/DAFx23_paper_23.pdf).
