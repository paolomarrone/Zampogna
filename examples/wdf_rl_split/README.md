# RL low/high-pass pair

Series RL WDF with simultaneous low-pass output across R and high-pass output across L.

Entry point: rl_split(x, cutoff).

References: [inductor reflectance](https://www.dsprelated.com/freebooks/pasp/Physical_Derivation_Wave_Digital.html), [series adaptor](https://www.dsprelated.com/freebooks/pasp/General_Series_Adaptor_Force.html).
